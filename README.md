# 2DGP_project_SEAL

## Seal Prototype

A pico2d prototype for the two-lane perspective arena described in `PRD.md`.
The current build uses colored geometry as temporary art and opens directly to
the arena layout.

### Run

```powershell
python -m pip install -r requirements.txt
python main.py
```

Use the left/right arrows or `A`/`D` to move. Press `Esc` to close the game.
Platform switching and boss behavior are planned for later steps.
