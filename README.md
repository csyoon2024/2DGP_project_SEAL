# 2DGP_project_SEAL

## Seal Prototype

A pico2d prototype for the two-lane perspective arena described in `PRD.md`.
The current build uses colored geometry as temporary art and opens directly to
the arena layout.

### Run

```powershell
python -m pip install -r requirements.txt
python main.py
```

Press `Esc` to close the game. The initial prototype is a static layout preview;
player controls and boss behavior are planned for later steps.
